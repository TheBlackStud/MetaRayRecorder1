1Mettre les fichiers sur GitHub

Extrayez complètement le ZIP sur votre PC. Vous n’avez pas besoin d’installer Xcode sur Windows.

Créer le dépôt GitHub
  1. Connectez-vous à GitHub, ou créez votre compte. Nommez le dépôt MetaRayRecorder, choisissez Private, puis Create repository.
  2. Sur la page du dépôt, choisissez uploading an existing file ou Add file → Upload files.
  3. Ouvrez le dossier extrait. Glissez son contenu dans la page d’envoi, y compris le dossier .github. N’envoyez pas simplement le ZIP ou le dossier parent contenant tout le projet.
  4. Validez avec Commit changes. Les dossiers ci-dessous doivent apparaître directement à la racine du dépôt.
.github/workflows/build-ios.yml
MetaRayRecorder/
MetaRayRecorder.xcodeproj/
Scripts/
Tests/
README.md

Avant de compiler, consultez les paramètres de facturation de votre compte GitHub. Un dépôt privé utilise votre quota Actions et peut entraîner des frais si vous autorisez le dépassement. Ce guide ne garantit pas un coût nul. Conditions des runners GitHub.

2Faire créer le fichier IPA

  1. Dans le dépôt, ouvrez l’onglet Actions. Activez les workflows si GitHub vous le demande.
  2. Sélectionnez Compiler IPA iPhone, puis Run workflow → Run workflow.
  3. Ouvrez l’exécution. Un Mac hébergé télécharge le SDK Meta, exécute les tests iOS et compile l’application pour un vrai iPhone.
  4. Lorsque l’exécution est verte, descendez jusqu’à Artifacts et téléchargez MetaRayRecorder-IPA.
  5. Extrayez cette nouvelle archive. Le fichier à installer est MetaRayRecorder-unsigned.ipa.

Le mot unsigned signifie « non signé ». La compilation ne nécessite pas votre compte Apple ; celui-ci sera utilisé localement à l’étape suivante.

L’exécution est rouge ou aucun IPA n’apparaît

Ouvrez la première étape en échec. Le code n’a pas passé la compilation ou les tests : il ne faut pas considérer l’application comme validée. Les journaux restent accessibles dans Actions et, si disponibles, dans MetaRayRecorder-diagnostics. Voir le dépannage. Aucun téléchargement IPA ne doit être attendu tant que cette étape échoue.

3Signer et installer sur l’iPhone

La méthode proposée utilise Sideloadly, un outil tiers pour Windows qui annonce la prise en charge d’un compte Apple gratuit. Téléchargez-le uniquement depuis son éditeur.

Ouvrir le site Sideloadly
  1. Installez Sideloadly pour Windows. Son site demande les versions web d’iTunes et iCloud, et non celles du Microsoft Store : suivez ses liens et instructions actuels.
  2. Branchez l’iPhone en USB, déverrouillez-le et acceptez Faire confiance à cet ordinateur.
  3. Ouvrez Sideloadly. Sélectionnez votre iPhone et glissez MetaRayRecorder-unsigned.ipa dans sa fenêtre.
  4. Renseignez votre compte Apple dans Sideloadly puis lancez Start. Terminez l’authentification demandée. Ne placez jamais votre mot de passe, code de validation ou certificat Apple dans GitHub, dans les sources ou dans une conversation.
  5. Sur l’iPhone, faites confiance à votre profil dans Réglages → Général → VPN et gestion de l’appareil, si cela est demandé. Activez aussi Réglages → Confidentialité et sécurité → Mode développeur si l’installation l’exige, puis suivez le redémarrage et la confirmation.

Compte gratuit : la signature expire après 7 jours. Il faut la renouveler. Sideloadly propose un renouvellement automatique lorsque ses conditions de connexion sont remplies. Gardez le même identifiant d’application et exportez vos vidéos avant toute désinstallation. Limites Apple.

La signature de ce projet et sa connexion au SDK Meta après installation n’ont pas encore été testées sur votre appareil. Un IPA compilé ne constitue pas, à lui seul, cette validation.

4Connecter les lunettes et filmer

  1. Ouvrez l’application officielle Meta AI sur l’iPhone, vérifiez que les Gen 2 y sont associées et activez le mode développeur Meta dans ses réglages. Ce mode est distinct du mode développeur de l’iPhone.
  2. Mettez les lunettes. Dans MetaRay Recorder : 1 · Connecter avec Meta AI, acceptez l’association, puis revenez dans MetaRay.
  3. Touchez Démarrer l’enregistrement. La session et le flux se préparent automatiquement. Autorisez la caméra dans Meta AI si demandé.
  4. Quand REC apparaît, verrouillez l’iPhone. Rouvrez cette application pour toucher Arrêter et sauvegarder.
  5. Pour le premier essai, arrêtez après quelques secondes et vérifiez le fichier dans Mes vidéos. Testez ensuite un enregistrement dépassant 5 minutes.

Pour enregistrer le son des lunettes

Avant d’ouvrir la caméra, allez dans les réglages de MetaRay, activez Enregistrer le son Bluetooth, recherchez les micros puis sélectionnez explicitement le port portant le nom de vos Ray-Ban. Le micro de l’iPhone ne sert pas de remplacement. En cas d’absence du port Bluetooth, laissez le son désactivé.

Pour retrouver les vidéos

Ouvrez Mes vidéos pour lire, partager ou ajouter un fichier dans Photos. Les fichiers finalisés sont également dans Fichiers → Sur mon iPhone → MetaRay Recorder → Enregistrements.

Ce que le code prévoit

Connexion au SDK Meta, aperçu réel, enregistrement H.264/AAC, sauvegarde locale, bibliothèque, partage et export Photos. Pas de minuterie d’arrêt ajoutée à 3 ou 5 minutes.

Les files d’encodage sont bornées. Une rupture de flux, un stockage bas ou une température iPhone élevée déclenche l’arrêt et la sauvegarde.

Ce qui n’est pas garanti

La durée de 20–60 minutes, l’autonomie et la synchronisation audio/vidéo doivent être testées. Le flux élevé demandé est 720 × 1280, pas 3K natif, et peut être dégradé par le SDK.

Le verrouillage ne provoque plus d’arrêt volontaire. Le SDK Meta peut continuer à livrer les images en arrière-plan ; iOS, le firmware ou les lunettes peuvent néanmoins interrompre la session. Le bouton physique des lunettes n’est pas une commande d’arrêt intégrée. L’arrêt s’effectue dans l’application. Une récupération après arrêt brutal reste une tentative.
